# E-Commerce Return & Refund Intelligence

## Project Overview
An end-to-end Data Analyst portfolio project analysing e-commerce orders, return reasons, refund requests, and potential return-abuse indicators.

## Tools Used
- **Python:** Pandas, NumPy, Matplotlib
- **SQL:** Microsoft SQL Server (SSMS)
- **Power BI:** Interactive dashboards, KPI cards, charts, and slicers

## Project Objectives
- Analyse e-commerce return and refund patterns.
- Identify the most common return reasons.
- Compare refund amounts across product categories.
- Explore customer segments and return-history indicators.
- Present business insights through an interactive Power BI dashboard.

## Dashboard Pages
1. Executive Overview
2. Returns & Refunds Analysis
3. Customer & Return Risk Insights

## Project Workflow
1. Data exploration and cleaning
2. SQL data validation and business analysis
3. Power BI dashboard development
4. Insights and recommendations

## Important Note
Potential abuse indicators are used for analytical exploration only. They do not independently prove fraud.
